# Go Calculator 🧮

A simple command-line calculator built with Go.  
It performs basic arithmetic operations: addition, subtraction, multiplication, and division.

---

## Features

- Basic operations: `+`, `-`, `*`, `/`
- Continuous calculation loop
- Safe division (prevents division by zero)
- Simple CLI interaction
- Clean and readable code with human-friendly comments

---

git clone https://github.com/YOUR_USERNAME/go-calculator.git
